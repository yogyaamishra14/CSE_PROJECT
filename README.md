# CSE_PROJECT
A Python-based Student Helper Chatbot with a Tkinter GUI that answers subject-related queries and solves basic mathematical expressions using safe parsing. It supports multiple domains like physics, chemistry, math, and computer science, providing quick definitions and calculations in an interactive interface.

Student Helper Chatbot (Python)

Features

* 💬 Interactive GUI using Tkinter
* 📚 Multi-subject support (Physics, Chemistry, Math, CS)
* 🧠 Answers definitions and concepts
* 🧮 Solves mathematical expressions (BODMAS supported)
* 🔒 Safe evaluation (no use of `eval()`)
* ⌨️ Supports both button click and Enter key


Technologies Used

* Python
* Tkinter (GUI)
* AST (for safe calculations)
* Regex (for input detection)
